# Nova-Data-Analytics-project
*INTRODUCTION

This project analyses NovaTrust Bank’s transaction data to evaluate its revenue as well as customer, branch, product, and profitability performance. The analysis focuses on five key business questions: which branches generate the highest revenue, which customer segments contribute most to revenue, which banking products have the highest transaction volumes, how monthly revenue changes over time, and how fee waivers affect profitability.
The data was first cleaned and prepared using Google Sheets. PostgreSQL was then used to query and organise the data, as well as establish relationships between the Customers, Branches, Products, and Transactions tables using primary and foreign keys.
Question 1: Which branch generates the highest revenue, and how does branch performance compare? 

###**Findings:
Kano Fagge Branch generated the highest revenue, with total revenue of ₦3,775,686.88. Kano Bompai Branch ranked second with ₦3,289,865.54, followed by Lagos Victoria Island Branch with ₦3,109,623.16.
The lowest-performing branch was Abuja Asokoro Branch, which generated ₦121,961.06. The results show a considerable variation in revenue performance across the branches.

###**Recommendation:
The strong performance of Kano Fagge and Kano Bompai branches suggests that there may be differences in customer activity, transaction volumes, product usage or fee collection across branches. NovaTrust Bank ought to investigate the factors contributing to the higher revenue of the leading branches and identify opportunities to improve the performance of the lower-revenue branches.
